📋 О проекте
PERCo-Web Аналитик — это десктопное приложение с графическим интерфейсом, разработанное для автоматизации расчёта фактического времени присутствия сотрудников на контролируемых объектах (помещениях) на основе данных системы контроля доступа PERCo-Web.

Программа позволяет в несколько кликов получить детализированный отчёт по каждому сотруднику с разбивкой по дням, итоговым временем и процентом выполнения месячной нормы.

🎯 Для кого этот инструмент?
👮 Специалисты по информационной безопасности — контроль фактического присутствия персонала на объектах

🏢 Службы охраны труда — учёт рабочего времени сотрудников на опасных производствах

📊 HR-специалисты — анализ посещаемости и трудовой дисциплины

🔧 Администраторы СКУД — выгрузка и аудит данных системы контроля доступа

🚀 Установка
📦 Автоматическая установка (рекомендуется)
Программа самостоятельно устанавливает все необходимые библиотеки при первом запуске в локальную папку lib/ — без вмешательства в системный Python.

bash
# 1. Клонируйте репозиторий
git clone https://github.com/yvkholostykh/perco-web-analyst.git
cd perco-web-analyst

# 2. Запустите приложение
python "PERCo-Web Analyst.py"
🔧 Ручная установка зависимостей
Если автоматическая установка не сработала:

bash
pip install pandas openpyxl requests urllib3 Pillow

🌐 Работа с API PERCo-Web
🔑 Требования
Для работы через API необходим установленный модуль:

PERCo-WM04 — «Интеграция с внешними системами»

🛣️ Используемые эндпоинты
Программа автоматически перебирает несколько вариантов путей для совместимости с разными версиями PERCo-Web:

Назначение	Эндпоинты
Авторизация	/api/system/auth, /system/auth, /api/auth/login, /auth/login
Список сотрудников	/api/users/staff/fullList, /users/staff/fullList
События проходов	/api/accessReports/events, /accessReports/events
🔐 Авторизация
http
POST /api/system/auth
Content-Type: application/json

{
    "login": "admin",
    "password": "your_password"
}
Ответ содержит token, который автоматически подставляется в заголовок:

http
Authorization: Bearer <token>
📐 Логика расчёта
🧮 Алгоритм
text
1. Группировка событий по сотрудникам (ФИО + Табельный номер)
   ↓
2. Сортировка событий по времени
   ↓
3. Построение интервалов присутствия:
   • Вход  (RRR → DDD) = начало интервала
   • Выход (DDD → RRR) = конец интервала
   ↓
4. Разбивка интервалов по календарным дням
   (с учётом перехода через полночь)
   ↓
5. Суммирование минут по каждому дню
   ↓
6. Расчёт процента от нормы:
   percent = (total_minutes / (norm_hours × 60)) × 100
🎨 Цветовая индикация
Диапазон	Цвет	Значение
≥ 100%	🟢 Зелёный	Норма выполнена
75% – 99%	🟡 Жёлтый	Норма почти выполнена
< 75%	🔴 Красный	Норма не выполнена

❓ Часто задаваемые вопросы
<details> <summary><b>❌ Ошибка: «Не удалось подключиться к серверу»</b></summary>
Возможные причины:

🔸 Неверный адрес сервера (проверьте доступность через браузер)

🔸 Не установлен модуль PERCo-WM04 (интеграция с внешними системами)

🔸 Блокировка запросов firewall'ом

🔸 Использование самоподписанного SSL-сертификата (программа уже игнорирует verify=False)

Решение: проверьте соединение командой:

bash
curl -k https://your-perco-server/api/system/auth
</details><details> <summary><b>❌ Ошибка: «Не найдены библиотеки»</b></summary>
Запустите программу от имени администратора или установите зависимости вручную:

bash
pip install --upgrade pandas openpyxl requests urllib3 Pillow
Для Pillow на Linux может потребоваться:

bash
sudo apt-get install python3-tk python3-pil python3-pil.imagetk
</details><details> <summary><b>❓ Почему время в отчёте отличается от фактического?</b></summary>
Программа считает только время между событиями Вход/Выход через контролируемую точку доступа. Если сотрудник:

Проходит через несколько турникетов

Имеет несколько карт доступа

Не всегда прикладывает карту

— данные могут отличаться. Для точного учёта рекомендуется использовать биометрические СКУД PERCo.

</details><details> <summary><b>❓ Поддерживается ли работа с несколькими объектами?</b></summary>
Да. Программа автоматически определяет все уникальные объекты из загруженных событий и предлагает их в выпадающем списке. Просто выберите нужный объект перед расчётом.

</details>
